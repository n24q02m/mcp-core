## 2025-03-27 - [Optimizing Bearer token parsing in Node.js HTTP servers]
**Learning:** String allocation (`substring()`, `trim()`, `toLowerCase()`) in the fallback path for parsing HTTP headers like `Authorization: Bearer` on every request adds measurable overhead and garbage collection pressure in Node.js/Bun environments.
**Action:** Replace multi-step string operations with a manual, single-pass pointer scan using `.charCodeAt()`. For case-insensitive equality checks on ASCII strings, use bitwise OR (`char | 0x20`) against the lowercase ASCII value. This avoids all string allocations except for the final token extraction and provides a fast execution path even when headers have irregular spacing or mixed casing.
